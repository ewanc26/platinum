# Every source under bridge/src/ and macos9/ (not tests), with who owns the logic.
# tools/check-flow.sh duplication fails on a source missing from this list, on a
# listed file that no longer exists, and on an owner outside these four:
#
#   platform  Mac UI, input, storage or event loop; nothing to share.
#   bridge    the bridge's own service code (HTTP, storage, the Platinum protocol).
#   protocol  the Platinum bridge protocol; Platinum owns the contract, not Wolfram.
#   atproto   the native AT Protocol client (URLs, identity, session, XRPC); no
#             bridge is in the path, so these files are the only place the Mac may
#             hold an AT Protocol method string. Marking a file atproto is what lets
#             tools/check-flow.sh duplication accept an NSID there.
#   port      a port of something Wolfram owns, kept only because the bridge is Node
#             and cannot call C. Must name the Wolfram issue or file it follows, and
#             is deleted when a binding exists.
#
# <path> <owner>  # reason
